Import at Scale in Blender

⚠️ Run in a new or empty scene. The script changes scene units. Open the .py file in Blender’s Scripting workspace.
  1. Click "📋 Copy Blender Script" above.
  2. Open Blender and select the Scripting workspace.
  3. In the Text Editor, click "+ New" and paste with Ctrl + V.
  4. Click Run Script (▶) (or press Alt + P).
  5. A Plane is created at the output dimensions. The image Empty starts hidden. Press Numpad 7 for a top view and independently verify a known distance.

Independent Distance Check

Select two points whose real distance is known and that were not used for calibration. Wheel: zoom · drag empty area: pan · drag A/B: move points. Reset to start a new pair.

Select points A and B.

This check applies only to the selected distance; it does not certify the whole image. Check horizontal and vertical distances in multiple regions. A ruler printed on a photocopy is not an independent reference unless its scale has been verified.
